# Установка среды и сборка

1. Установить Android Studio и Flutter SDK stable.
2. Выполнить `flutter doctor` и устранить отмеченные ошибки.
3. Распаковать проект в каталог без кириллицы и пробелов.
4. Открыть корень проекта в Android Studio.
5. В терминале выполнить:
   - `flutter pub get`
   - `flutter run` — запуск на подключённом телефоне;
   - `flutter build apk --debug` — сборка APK.

Для телефона включить «Для разработчиков» и «Отладка по USB».
