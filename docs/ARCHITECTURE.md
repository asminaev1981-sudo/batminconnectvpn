# Архитектура v0.2.0

- `lib/core` — API, конфигурация, модели, сервисы, тема.
- `lib/features` — независимые пользовательские экраны.
- `ConnectionController` — единая модель состояния туннеля.
- `BatminApi` — HTTP-клиент Batmin Platform.
- Android-слой пока содержит Flutter Activity; VpnService и libbox добавляются следующим этапом.

Границы модулей позволяют заменить имитацию подключения реальным движком без переписывания интерфейса.
