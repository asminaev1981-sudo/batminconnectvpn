# Batmin Connect v0.3.0 — Android VPN Bridge

Рабочий этап интеграции Flutter с Android `VpnService`.

## Реализовано

- запрос системного разрешения Android на создание VPN;
- Flutter ↔ Kotlin `MethodChannel`;
- foreground `VpnService` с постоянным уведомлением;
- команды `prepare`, `start`, `stop`, `status`;
- безопасный каркас для подключения libbox;
- Android 14/15 foreground-service declarations.

## Важное ограничение

В этой версии TUN-интерфейс намеренно **не создаётся** и трафик не перенаправляется. До подключения libbox пустой TUN обрывал бы доступ в интернет. Версия проверяет разрешения и жизненный цикл системного VPN-сервиса, но ещё не является рабочим VPN-клиентом.
